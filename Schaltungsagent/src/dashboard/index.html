    Agenten-Ausführung
    
                            —
                        
    
                        
    Produktiv laufen die OpenCode-Agenten immer isoliert in Docker. Die native Ausführung ist nur als Testweg für Rechner ohne ausreichende Docker-Leistung gedacht.
    
                        
    
                            Testmodus aktiv: Die Agenten laufen direkt auf dem Host und haben Zugriff auf alle Dateien des Benutzers. Nicht für Produktivumgebungen verwenden.
                        
    
                        
    
                            Der Testmodus wird beim Start erzwungen (--test-mode bzw. VHDL_AGENT_TEST_MODE) und überschreibt diese Einstellung bis zum nächsten Start ohne diese Option.
